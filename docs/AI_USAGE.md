# Использование ИИ

Этот документ нужен для прозрачного описания помощи ИИ при выполнении тестового задания. Его следует обновлять по мере работы.

## Текущее использование

ИИ использовался для:

- подготовки начального технического каркаса проекта;
- настройки базовой структуры PHP, Smarty, Docker и SCSS;
- составления плана реализации и чек-листа проверки;
- подготовки учебной шпаргалки по SQL и PDO с примерами для этого проекта;
- обсуждения архитектурных вариантов и потенциальных ошибок.

На текущем этапе предметная логика блога, структура SQL-запросов, страницы категорий и статей, пагинация и сидеры не реализованы.

## Правило обновления

Если ИИ помогает с конкретным фрагментом кода, проверкой ошибки, SQL-запросом или текстом документации, это нужно кратко добавить в список выше. Финальное описание должно точно соответствовать реальному процессу работы.
