# PHP + Smarty Blog

Стартовый каркас тестового задания: чистый PHP 8.1+, MySQL и Smarty без фреймворков.

## Первый запуск

1. Создайте локальный файл окружения:

   ```bash
   cp .env.example .env
   ```

2. Установите зависимости и соберите стили:

   ```bash
   composer install
   npm install
   npm run css:build
   ```

3. Запустите контейнеры:

   ```bash
   docker compose up --build
   ```

Сайт будет доступен по адресу <http://localhost:8080>.

## Подготовка базы данных

Создайте таблицы приложения:

```bash
docker compose exec app php bin/migrate.php
```

## Тестовые данные

Сидер очищает таблицы блога и добавляет демонстрационные категории, статьи и связи между ними:

```bash
docker compose exec app php bin/seed.php
```

Команду следует использовать только для локальной разработки, поскольку существующие данные блога будут заменены.

## Структура

- `public/` — публичная точка входа и статические файлы;
- `src/` — PHP-код приложения;
- `templates/` — Smarty-шаблоны;
- `routes/` — маршруты сайта;
- `database/` — будущие миграции и сидеры;
- `resources/scss/` — исходники стилей;
- `storage/` — кэш и скомпилированные шаблоны;
- `docker/` — конфигурация окружения.
