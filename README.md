# PHP + Smarty Blog

Рабочий блог на чистом PHP 8.1+, MySQL и Smarty без PHP-фреймворков.

## Первый запуск

1. Создайте локальный файл окружения:

   ```bash
   cp .env.example .env
   ```

2. Запустите контейнеры:

   ```bash
   docker compose up -d --build
   ```

3. Создайте таблицы и демонстрационные данные:

   ```bash
   docker compose exec app php bin/migrate.php
   docker compose exec app php bin/seed.php
   ```

Откройте <http://localhost:8080>.

Сидер очищает таблицы блога перед заполнением, поэтому предназначен только для локальной разработки.

## Разработка стилей

Для изменения SCSS установите зависимости и запустите наблюдение:

```bash
npm install
npm run css:watch
```

Однократная сборка:

```bash
npm run css:build
```

Остановить локальное окружение можно командой `docker compose down`.

## Возможности

- главная с тремя последними статьями каждой непустой категории;
- страница категории с сортировкой и пагинацией;
- страница статьи со счётчиком просмотров;
- категории статьи и три похожих материала;
- миграция, повторяемый сидер, страницы 404 и 500;
- адаптивный интерфейс на SCSS.

## Структура

- `public/` — публичная точка входа и статические файлы;
- `src/` — PHP-код приложения;
- `templates/` — Smarty-шаблоны;
- `routes/` — маршруты сайта;
- `database/` — SQL-миграции и сидеры;
- `resources/scss/` — исходники стилей;
- `storage/` — кэш и скомпилированные шаблоны;
- `docker/` — конфигурация окружения.

## Архитектура

HTTP-запрос проходит через единую точку входа и маршрутизатор в контроллер. Контроллер получает данные из репозиториев и передаёт готовый массив в Smarty. SQL находится только в репозиториях.

## Проверка PHP

```bash
find public routes src bin database/seeders -name '*.php' -print0 \
  | xargs -0 -n1 php -l
```
